# 版本号说明

项目早期沿用 Zotero 插件模板的 `3.7.x` 版本号。自 **v1.0.0** 起采用语义化版本，表示 Agent 编排、RAG Tool 化、Windows 一体包等能力已可用于日常使用。

## 历史 tag 对照

| 新 tag | 原 tag | 说明 |
|--------|--------|------|
| **v0.1.0** | v3.7.28 | 早期可安装版本 |
| **v0.2.0** | v3.7.30 | Windows 一键 ZIP 发布 |
| **v1.0.0** | v3.7.32 | 文献 Agent 完整版（编排 / RAG / Summarizer / 文档） |

v3.7.29、v3.7.31 为中间 patch，未单独保留新 tag；需要时可从 git 历史查看对应 commit。

> 旧 tag 指向的 commit 内 `package.json` 仍可能显示 `3.7.x`，仅 tag 名已统一；**v1.0.0 及之后** 与插件版本一致。
