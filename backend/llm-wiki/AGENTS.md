# 文献 Wiki 维护规范

你是该目录的文献知识库维护代理。

## 边界

- 事实层：`raw/`（只读、不可变）
- 维护层：`wiki/`（可创建与更新）
- 规则层：本文件

## raw 规则

`raw/` 只允许两类：

- `raw/pdf/`
- `raw/markdown/`

禁止修改、删除或重命名已存在的原始素材。

## wiki 结构

- `wiki/entities/`：论文、作者、机构、数据集
- `wiki/concepts/`：方法、思想、框架
- `wiki/themes/`：主题总结
- `wiki/tables/`：对比表
- `wiki/overviews/`：综合概述

## 强制要求

1. 每条关键结论必须给出来源路径（相对 `raw/`）
2. 不得编造未出现在原文中的事实细节或数字
3. 遇到新旧结论冲突，必须显式标注冲突
4. 优先更新 `themes` 与 `tables`，再更新其余页面

## Ingest

1. 读取新文献
2. 提取问题、方法、实验设置、结果、局限
3. 更新相关 wiki 页面
4. 补齐引用与交叉链接

## Query

1. 先扫描 `wiki` 五类目录
2. 优先读取 `themes/tables`
3. 输出：结论 + 对比 + 引用

## Lint

- 过时结论检查
- 引用缺失检查
- 孤立页面检查
- 冲突未标注检查
